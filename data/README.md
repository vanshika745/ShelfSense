# Dataset folder

ShelfSense works with **any** shop sales file you upload in the app. To try the built-in demo, download this dataset:

**Online Retail II**, UCI Machine Learning Repository (licence: CC BY 4.0)
https://archive.ics.uci.edu/dataset/502/online+retail+ii

1. Click **Download** on the page above (file `online+retail+ii.zip`, about 45 MB).
2. Unzip it and place **`online_retail_II.xlsx`** in this folder:

```
ShelfSense/data/online_retail_II.xlsx
```

The first time you load the demo, ShelfSense converts the Excel file to `online_retail_II.csv`, which takes about 1–2 minutes. After that it loads much faster.

Citation: Chen, D. (2012). Online Retail II [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D
